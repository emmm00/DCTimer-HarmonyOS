# 应用市场介绍图

华为 AGC 上架用，8 张竖版截图。

## 规格

| 项目 | 要求 | 实际 |
|---|---|---|
| 数量 | 3~10 张 | 8 张 |
| 比例 | 9:16 | 9:16 |
| 尺寸 | 最小 1080×1920 | 1080×1920 |
| 格式 | PNG / JPG / JPEG | PNG |
| 大小 | 单张 ≤ 5MB | 187~365 KB |

## 制作方式

截图来自模拟器真机渲染（Mate 90 Pro / 1280×2832 / HarmonyOS API 26），跑出 16 条真实成绩后逐页采集，再合成到 1080×1920 画布：

- 底层是应用内置的「极光」渐变（`AmbientTheme.ets` 里同一套色值），保证和 App 本体观感一致。
- 截图居中偏下，30px 圆角 + 高斯投影。
- 顶部品牌名 + 两行标题 + 副标题，浅色用深墨字、深色用白字。

重新生成脚本：`%TEMP%\mkfinal.py`（Pillow）。

## 注

截图里的成绩数据是真实操作产生的（最佳 15.70、平均 18.71），不是编的。
