DC Timer 是一款专为魔方爱好者打造的专业计时与训练工具，现已原生适配鸿蒙系统，为你带来流畅、精准的魔方练习体验。

【精准计时】
- 触屏启停，还原后轻触屏幕即可停止计时，支持厘秒 (0.00) 与毫秒 (0.000) 双精度自由切换
- 支持 WCA 标准 15 秒观察倒计时，超时自动判 +2 / DNF，模拟真实比赛环境
- 可自定义启动延时，按住屏幕显示绿色后松手开始，防止误触
- 成绩确认支持无惩罚、+2 秒、DNF 三种判罚，完全符合 WCA 规则
- 支持分段计时（1~3 段），观察回看每一段的用时

【丰富打乱】
- 覆盖全部 WCA 官方项目：二阶、三阶、四阶、五阶、六阶、七阶、三阶单手、三阶盲拧、
  四阶盲拧、五阶盲拧、三阶多盲、三阶最少步、金字塔、五魔方、Square-1、Clock、Skewb、FTO
- 提供打乱状态图预览，直观查看打乱后的魔方状态
- 内置 141 种打乱类型、22 个分类，包含大量训练向子集：
  3x3 分类含 F2L、OLL、PLL、ZBLL、ELL、CLL、CMLL+LSE 等 CFOP/Roux 专项，
  4x4 / 5x5 含 edges（对棱）专项，另有 2x2 的 CLL/EG/PBL、金字塔 L4E、斜转 L2L 等
- 左右滑动快速切换打乱公式

【强大统计】
- 自动记录每次还原成绩，支持手动输入；点开单条成绩可改判罚、写备注、复制打乱或删除
- 实时显示当前分组最快、最慢成绩，以及分组平均值与标准差
- 两组可独立配置的滚动平均：长度支持 3 / 5 / 12 / 50 / 100，
  并可在「平均 (ao)」与「均值 (mo)」之间切换，自动剔除最快与最慢成绩
- 滚动平均随成绩即时刷新，追踪近期状态起伏
- 成绩趋势折线图，直观展示进步轨迹
- 成绩支持导出为 CSV，一键复制到剪贴板

【多分组管理】
- 支持创建多个训练分组，按项目或阶段分别记录
- 每个分组独立统计，互不干扰
- 点击成绩页标题栏的 ✕ 可一键清空当前分组成绩（带二次确认）

【便捷手势】
- 向左滑动：删除上一次成绩
- 向右滑动：切换新的打乱公式
- 向上滑动：修改上一次成绩的判罚
- 向下滑动：手动输入成绩
- 四个方向的手势均可自定义，也可关闭

【求解辅助】
- 三阶：十字 / CFOP / 桥式 / ZZ-EOLine / Petrus 五种方法逐步拆解，可切换底色
- 二阶：面先法、一层法
- 金字塔：逐面求解
- Square-1：FTM（面转）与 TTM（扭转）两种度量
- 求解在后台线程完成，界面不卡顿

【个性外观】
- 支持浅色 / 深色 / 跟随系统三态主题
- 沉浸光感：顶栏与弹窗采用系统材质毛玻璃，配合可切换的内置渐变底色
- 可自定义背景图片、计时器字号、打乱公式字号、配色方案

无论你是刚入门的魔方新手，还是追求极限的速拧高手，DC Timer 都能满足你日常训练和比赛模拟的需求。纯净无广告，专注你的每一次还原。
