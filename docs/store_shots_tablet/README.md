## 制作方式

**没有在平板上重新真机截图**，是从手机版（`../store_shots/`）的同一批 1280×2832 源图重新编排成横版：

- 左侧：原比例缩放到高 1080（宽约 488），26px 圆角 + 高斯投影，不做非等比拉伸。
- 右侧：品牌名 + 两行大标题 + 一行副标题 + 三条卖点（圆点标记）。
- 底层沿用应用内置「极光」渐变的同一套色值。
- 文案里的数字（步数、题数、成绩）都来自代码核实，不是凑的。

重新生成脚本：`%TEMP%\mktablet2.py`（Pillow）。

## 与手机版的差异

平板版比手机版多三条卖点，因为 3:2 横向留白更多，纯标题会显得空。手机版（1080×1920）只有品牌名 + 标题 + 副标题。
